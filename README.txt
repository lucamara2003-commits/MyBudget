MY BUDGET - APP PWA PER IPHONE

Questa cartella contiene una PWA offline. I dati sono salvati in localStorage sul dispositivo/browser.
Per installarla come icona su iPhone serve pubblicare questi file su un indirizzo HTTPS (es. GitHub Pages).

PASSAGGI:
1. Crea un repository GitHub chiamato my-budget (puoi renderlo pubblico).
2. Carica TUTTI i file di questa cartella nella cartella principale del repository.
3. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch > branch main > /(root) > Save.
4. Attendi la pubblicazione e apri l'indirizzo HTTPS generato da GitHub Pages in Safari sull'iPhone.
5. Premi Condividi (quadrato con freccia) > Aggiungi alla schermata Home > Aggiungi.
6. Avvia My Budget dalla nuova icona.

NOTE:
- Il sito va aperto in Safari e deve essere servito via HTTPS perché l'installazione PWA/offline funzioni.
- Le spese sono locali al browser/dispositivo, non vengono sincronizzate con altri telefoni.
- Esporta regolarmente il backup. Per importare un backup, tocca a lungo il pulsante in alto a destra e seleziona il file JSON.
- Se cancelli i dati di Safari o rimuovi i dati del sito, potresti perdere le spese.
